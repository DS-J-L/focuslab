# 사이드바 문구 50개

앱을 실행하면 아래 문구 중 하나를 무작위로 표시합니다. 창을 열어 둔 동안에는
10분마다 다음 문구로 바뀝니다. 한 번 실행한 앱에서는 50개를 모두 보여준 뒤
다시 섞으며, 같은 문구가 바로 이어서 나오지 않습니다. 트레이에 숨기거나
최소화한 동안에는 문구를 바꾸지 않습니다.

문구 선택은 기기 안에서만 이루어지며, 실제 활동 기록이나 집중 시간을 읽거나
분석하지 않습니다. 영어 UI에서는 같은 뜻의 영어 문구를 표시합니다.
