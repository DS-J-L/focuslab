# 앵무새 쓰다듬기

집중 세션의 앵무새 오버레이에서 머리나 볏 위에 포인터를 올린 뒤, 클릭하지 않고
위아래로 두세 번 움직이면 쓰다듬을 수 있습니다. 세 마리 모두 반응하며,
일시정지 중 목걸이 동작이 비활성화된 노란 앵무새도 쓰다듬을 수 있습니다.

쓰다듬는 동안에는 기존 옆보기 이미지의 눈을 부드럽게 감고 고개를 조금 기댑니다.
작은 하트가 떠오른 뒤 사라지고, 포인터를 떼어도 약 20초 동안 편안한 자세와
느린 눈 깜빡임이 남습니다. 같은 앵무새를 다시 쓰다듬으면 여운이 연장됩니다.
기분이 좋은 동안에는 자발적인 행동과 비행을 잠시 쉬며, 이후 기존 상태로 돌아갑니다.
최소 움직임 설정에서는 추가 고개 움직임이나 하트 입자 이동 대신 표정과 정적인
하트로 반응합니다. 원래 캐릭터 이미지와 옆을 보는 기본 방향을 유지합니다.

한 번 스쳐 지나가기, 작은 포인터 떨림, 수평 이동, 오래 떨어진 움직임은 쓰다듬기로
세지 않습니다. 새 앵무새로 옮기거나 오버레이를 숨기거나 접으면 미완성 동작이
초기화됩니다. 목걸이 클릭과 키보드 조작, 창 이동은 기존 기능을 그대로 사용합니다.

이 반응은 캐릭터의 일시적인 시각 효과입니다. 집중도 판단이나 세션 시간, 휴식 및
일시정지 상태를 바꾸지 않습니다. 오버레이 안의 Qt 포인터 이벤트만 사용하며,
화면 전체의 마우스를 감시하거나 위치를 저장하지 않습니다.

## 확인

- `pytest tests/unit/test_petting.py tests/e2e/test_parrot_petting.py`: 동작 구분,
  세 마리의 개별 반응, 20초 여운과 만료, 부정확한 입력 제외, 클릭 및 세션 보존.
- 기존 오버레이/비행 회귀 검사로 목걸이, 키보드, 창 이동과 상태 반응을 검증합니다.
- `FocusLab.exe --selftest-petting-report <absolute-report.json>`: 실제 EXE 안에서
  격리된 Qt 호버 이벤트로 세 마리를 쓰다듬고, 표정과 하트 렌더링, 여운 및 만료,
  클릭 미발생을 확인합니다. 센서, 사용자 DB와 실제 화면 포인터를 사용하지 않습니다.
  결과 JSON 옆에 렌더링된 PNG도 저장합니다. CI의 패키지 검사에서 실행합니다.
- 실제 마우스 확인: 앵무새 머리 위를 클릭 없이 세 번 정도 위아래로 움직인 뒤
  하트와 표정을 확인하고, 손을 뗀 뒤 편안한 표정이 잠시 남는지 봅니다.
