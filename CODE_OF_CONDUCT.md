# Community code of conduct

Contributors and maintainers should communicate respectfully, explain disagreements with evidence, and welcome different backgrounds and levels of experience.

Harassment, discrimination, threats, sexualized conduct, doxxing, and sharing other people's observations or recordings without consent are not acceptable. Keep feedback relevant to the work and respect privacy.

For ordinary conduct problems, contact the maintainer through an appropriate existing GitHub contact channel. Do not publish private evidence in issues. If no private channel is available, request a private contact without identifying affected people publicly.

Maintainers may edit or remove harmful content, warn participants, or restrict participation as appropriate. Maintainer decisions should be consistent, proportionate, and respectful of confidentiality. These expectations apply to repository discussions, issues, pull requests, and project spaces.
