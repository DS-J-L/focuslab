# FocusLab parrot icon

Created with the built-in image generation tool for FocusLab. The PNG is the source
for the application/window icon and tray mascot; the ICO contains Windows icon sizes
16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels for the executable.

Generation prompt:

> Use case: logo-brand. Asset type: Windows desktop application icon for FocusLab.
> Create ONE polished square icon, a friendly parrot holding a handheld telescope up
> to its eye and looking through it. The parrot and telescope must both be instantly
> recognizable. Clean modern flat mascot illustration with bold simple silhouettes,
> smooth rounded shapes, a few large color regions, very restrained shading, excellent
> legibility at 32 and 64 pixels. Compact close framing of the parrot's head and upper
> body, three-quarter side view, one wing clearly gripping the telescope, telescope
> projecting diagonally upward. Cheerful emerald/teal parrot, warm yellow-orange curved
> beak, deep indigo telescope with a pale blue lens. This is the complete app icon asset,
> not a mockup or presentation. Center the whole silhouette with a modest safe margin.
> Genuinely transparent background. No containing badge, no background tile, no
> landscape, no text, no letters, no watermark, no decorative objects, no extra birds.
> Deliver a crisp high resolution square PNG with alpha.
