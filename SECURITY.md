# Security policy

## Supported versions

FocusLab is pre-release scaffolding. No production-ready release or security support SLA is available yet.

## Reporting a vulnerability

Do not place secrets, personal observations, recordings or exploit details in public issues.
Use this repository's **Security → Advisories → Report a vulnerability** once private reporting is enabled. If that button is unavailable, open a public issue titled `Private security contact requested` without sensitive details; the maintainer must establish a private reporting channel before you send details.

Please include the affected revision, Windows/Python version, sanitized reproduction steps, and impact in the private report. The maintainer will triage reports on a best-effort basis.
